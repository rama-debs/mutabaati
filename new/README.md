# متابعتي 1.0.0

تطبيق عربي RTL من الصفر، بلا React أو مكتبات أو بناء npm. البيانات في localStorage على الجهاز، والعمل دون اتصال بعد أول فتح من رابط HTTPS.

## نشر GitHub Pages
1. أنشئي مستودعًا جديدًا وارْفعي محتويات هذا المجلد إلى الجذر، بما فيها `.nojekyll`.
2. Settings → Pages → Deploy from a branch → main → / (root) → Save.
3. افتحي رابط Pages في Safari. مشاركة → إضافة إلى الشاشة الرئيسية.
4. افتحي التطبيق مرة مع الإنترنت؛ بعد ذلك يمكن فتحه دون اتصال.

لا يحتوي الملف المضغوط على أي بيانات شخصية مسجّلة. تظل البيانات مرتبطة بالرابط والجهاز والمتصفح. تغيير الرابط لا ينقل البيانات: صدّري JSON ثم استورديه في الرابط الجديد.

## النسخ الاحتياطي
أهدافي → بياناتي → تصدير JSON. الاستيراد يحتاج تأكيدًا داخل الصفحة ويستبدل المفاتيح المطابقة. CSV يصدر ملفي الأيام والمسؤوليات. التقويم يضم سبعة أيام من الصلاة، مع حساب كل تاريخ مستقلًا، ومواعيدك المحددة بوقت ومراجعة الأحد.

## المحتوى المرافق
دليل الغسيل مسترجع من النسخة الموجودة. أضيفت ٢٩ دعاءً وذكرًا وحكايتان من ملفي PDF المرفقين، مع الملاحظات والأسئلة. الأدلة الأربعة الأصلية لم تكن متاحة. يمكن تحرير المحتوى أو استيراد مصفوفات JSON من داخل التطبيق. بقية الأدلة صفحات مختصرة جديدة معلّمة بذلك. لم يُنسخ تصميم التطبيق السابق.

## تحديث التطبيق
غيّري VERSION في index.html وsw.js معًا عند نشر تحديث، ثم أعيدي فتح التطبيق مع الإنترنت. لا تحذفي localStorage أثناء التحديث.

## الحدود
لا حسابات، لا مزامنة، لا إشعارات خلفية. تنبيهات التقويم تعتمد على تطبيق التقويم وإعداداته. الحساب الغذائي تقديري. أوقات الصلاة تقديرية، وتحتاج مطابقة جدول مسجدك؛ المنطقة الزمنية تؤخذ من الجهاز.

التطبيق الكامل: index.html. ملفات البيانات: duas.js، tales.js. الأيقونات والـmanifest وsw.js ملفات دعم PWA.
